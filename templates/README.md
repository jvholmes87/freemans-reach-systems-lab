# Public Template Index

These templates support sanitized public systems-engineering artifacts without duplicating private project controls.

## Available Templates

- [Systems-Engineering Artifact Pack](SYSTEMS_ENGINEERING_ARTIFACT_PACK.md)
  - Architecture Decision Record
  - Requirements and Traceability Record
  - Trade Study
  - Risk and Reliability Register
  - Verification and Validation Plan
  - Research Bibliography Record
- [Public Release Checklist](PUBLIC_RELEASE_CHECKLIST.md)

## Use Rules

1. Copy only the section needed for the new public artifact.
2. Mark the artifact as **Public / Non-Authoritative**.
3. Use placeholders until information is cleared; never fill gaps from memory.
4. Separate evidence, assumptions, extrapolation, proposed canon, and approved canon.
5. Remove private Drive links and internal-only record content.
6. Complete the public release checklist before publication.
7. Record meaningful releases in `CHANGELOG.md`.

These templates are process aids. They do not authorize a canon, technical, or disclosure decision.
