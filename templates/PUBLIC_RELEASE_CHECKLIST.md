# Public Release Checklist

> **Status:** Public / Non-Authoritative Control  
> Complete this checklist before publishing a Freeman’s Reach artifact.

## 1. Authority and Status

- [ ] The artifact’s public purpose and status are stated.
- [ ] The latest applicable private authoritative records were checked.
- [ ] The artifact does not claim that GitHub is authoritative.
- [ ] Any canon statement was already approved and recorded privately.
- [ ] Proposed, assumed, unresolved, rejected, and superseded material is labeled or excluded.

## 2. Technical and Research Integrity

- [ ] Technical claims are supported by public evidence or clearly labeled extrapolation.
- [ ] No unsupported numerical performance, reliability, cost, schedule, or capability is presented as settled.
- [ ] Sources are cited and legally linkable.
- [ ] Restricted research files are not redistributed.
- [ ] Model limits, uncertainty, interfaces, dependencies, and failure modes are disclosed where material.

## 3. Story, Intellectual Property, and Rights

- [ ] Manuscript text, major reveals, and protected story material are excluded unless specifically cleared.
- [ ] Unapproved visual concepts are not presented as official canon.
- [ ] Third-party text, images, diagrams, trademarks, and datasets are used only with appropriate rights or under a valid exception.
- [ ] The artifact’s license or rights statement is clear when needed.

## 4. Privacy and Security

- [ ] No private Google Drive link appears.
- [ ] No internal AI conversation, handoff, or private creator-contribution record appears.
- [ ] No credential, token, personal data, employer-sensitive information, or client-sensitive information appears.
- [ ] File metadata and embedded links were checked.

## 5. Repository Quality

- [ ] The filename and path are stable and descriptive.
- [ ] Navigation indexes and the README are updated when needed.
- [ ] The public change log records the release when meaningful.
- [ ] Links render correctly.
- [ ] Placeholders, comments, and internal instructions were removed.
- [ ] The artifact is understandable without access to private records.
