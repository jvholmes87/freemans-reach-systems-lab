# Public Research and Bibliography Organization

> **Status:** Public / Non-Authoritative  
> This directory organizes only research cleared for public release. The private Research Register and Research Library remain authoritative.

## Publication Model

Public research artifacts should be organized by a stable research question or system topic, not by private folder layout. Each artifact should distinguish:

1. **Question** — what the research is trying to determine.
2. **Scope** — included and excluded claims.
3. **Evidence** — public, legally linkable sources.
4. **Finding** — what the sources support.
5. **Uncertainty** — limits, conflicts, and open evidence gaps.
6. **Engineering implication** — consequences for requirements or alternatives.
7. **Canon effect** — normally none unless separately approved in the private authority.
8. **Provenance** — author/reviewer, dates, and public revision history.

## Recommended Artifact Pair

For a mature public research topic, use:

- `TOPIC_RESEARCH_SYNTHESIS.md` for the question, evidence analysis, findings, uncertainty, and implications;
- `TOPIC_BIBLIOGRAPHY.md` for normalized source records and source-specific notes.

Do not create either file until there is approved public content to place in it.

## Bibliography Record Fields

| Field | Purpose |
| --- | --- |
| Source ID | Stable local identifier such as `PUB-BIB-001` |
| Full citation | Author, title, venue/publisher, year |
| Public locator | DOI or stable public URL |
| Source type | Paper, standard, handbook, dataset, archive, or institutional page |
| Accessed | Date the public locator was checked |
| Relevance | Question or requirement supported |
| Evidence role | Background, direct evidence, method, comparison, or constraint |
| Quality notes | Authority, peer review, version, sample/model limits |
| Rights notes | Link-only, quotation limit, license, or redistribution constraint |
| Status | Candidate, reviewed, cited, superseded, or rejected |
| Related artifact | Public synthesis, requirement, trade study, or verification record |

## Citation and Disclosure Rules

- Prefer primary literature, standards, official datasets, and authoritative institutional sources.
- Link to sources; do not upload restricted or copyrighted research files.
- Keep quotations short and necessary.
- Record conflicting findings and negative evidence.
- Do not convert a research finding directly into canon.
- Exclude private annotations, private links, internal handoffs, personal data, and client-sensitive material.
- Use the [public release checklist](../../templates/PUBLIC_RELEASE_CHECKLIST.md) before publication.
