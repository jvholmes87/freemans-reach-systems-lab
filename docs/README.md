## Publication Rules

Public documentation must:

- Identify its status and purpose.
- Avoid private Drive links, internal handoffs, restricted files, personal information, client-sensitive material, spoilers, and unapproved canon.
- Separate evidence, engineering extrapolation, working assumptions, and fictional canon.
- Link to public artifacts rather than reconstructing private records.
- Use the public release checklist before publication.
